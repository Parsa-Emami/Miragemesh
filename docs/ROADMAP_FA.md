# رودمپ متن‌باز MirageMesh

هدف، سورس کامل Apache-2.0 و اجرای محلی بدون حساب پولی/ابری، دامنهٔ عمومی یا کلون پروژهٔ دیگر است. `npm run setup` و `npm start` اکنون وب و پردازش Go محلی را با یک ترمینال اجرا می‌کند. C03 فقط چرخهٔ اجرا و سلامت/نسخه را فراهم می‌کند؛ پردازش دامنه و C17 هنوز آماده نیستند. پیش‌نیازها Go نصب‌شده، Podman بدون root و نسخه‌های قفل‌شدهٔ Node/npm هستند.

در plans/commits برای هر C01 تا C40 یک کارت با مسیر فایل‌ها، گام‌های دقیق، پیش‌نیاز، منابع، سخت‌افزار، دادهٔ آزمایشی و مجوز، حالت خطا، فرمان آزمون، شواهد و بازگشت وجود دارد. فرمان‌های وابسته به موتور آینده صریحاً علامت خورده‌اند.

- C01–C06: قرارداد استفاده، نسخه‌های قفل‌شده، موتور واقعی، قرارداد داده، ذخیره‌سازی و CI.
- C07–C26: بیست قابلیت تخصصی همین پروژه همراه آزمون و اتصال واقعی وب.
- C27–C30: امنیت، ظرفیت اندازه‌گیری‌شده، سلامت موتور، نصب از کلون، انجام کار اصلی و بازیابی. **C30 نخستین نقطهٔ قابل بهره‌برداری محلی است**، پس از تأیید واقعی همهٔ این موارد.
- C31–C38: بستهٔ کامل موتور/وب و سورس، مجوزها، نصب/میزبانی اختیاری، UX، مستندات، ارتقا و تکرار مستقل نصب و رفع موانع.
- C39–C40: کنترل شواهد انتشار و نصب نسخهٔ واقعاً منتشرشده. **C40 پایان نسخهٔ کامل متن‌باز v1 است.**

ایجنت از AGENTS.md و قرارداد اجرا شروع می‌کند و با `npm run plan -- next` کار بعدی را می‌گیرد. هیچ آزمون اجرا‌نشده یا قابلیت ناقصی انجام‌شده ثبت نمی‌شود. محدودیت دائمی schema دیتابیس، migration، .env و Dockerfile برقرار است.

C04 قرارداد نسخهٔ ۱ و فرمان محلی `miragemesh --validate-event` را برای بررسی ساختار `http.request` و `metadata.path` فراهم می‌کند. این بررسی احراز هویت، پذیرش رویداد یا ذخیره‌سازی نیست؛ ورودی بیش از ۸ KiB، نسخهٔ ناسازگار و خطاهای داده صریح رد می‌شوند.

C05 ذخیره‌سازی داخلی Go را با یک نویسنده، سقف صریح، انتشار اتمیک manifest و بازیابی پس از قطع پردازش فراهم می‌کند. این قابلیت هنوز به HTTP یا UI متصل نیست و اثبات احراز هویت، ingest، دوام در قطع برق یا آمادگی محصول نیست؛ جزئیات در `docs/architecture/STORAGE_PROOF.md` آمده است.

C06 طبق محدودهٔ تأییدشدهٔ N06، workflow اختصاصی موتور و کنترل اجرای آزمون‌های C03–C05 را اضافه می‌کند. حذف مجموعهٔ آزمون، skip شدن تست ضروری یا خروجی ناقص خطا می‌دهد. آزمون‌های واقعی Go در کلون تمیز هم اجرا می‌شوند؛ جزئیات در `docs/engineering/ENGINE_TESTS.md` است. اعتبارسنجی محلی اجرای remote در GitHub Actions یا قابلیت امضا، revision، هویت و جداسازی شبکه را اثبات نمی‌کند؛ این قابلیت‌ها متعلق به کارت‌های بعدی‌اند.

C07 پذیرش تایپ‌شدهٔ رویداد را بر پایهٔ اعتبارسنجی C04 و ذخیره‌سازی پایدار C05 اضافه می‌کند. توالی هر سنسور از ۱ آغاز می‌شود، retry با همان بایت‌ها همان رسید را برمی‌گرداند و پس از بازگشایی ذخیره‌ساز، توالی ادامه می‌یابد. این قابلیت هنوز endpoint دریافت، enrollment یا mTLS ارائه نمی‌کند؛ آن‌ها در کارت‌های بعدی‌اند.
