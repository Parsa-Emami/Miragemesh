# MirageMesh security matrix (C27 / N27)

Status: verified for the source recorded in `docs/evidence/C27.json`. This is a
local Linux profile proof, not a security certification and not a claim about
hosted, multi-tenant or public-ingress deployments. The threat model is
`docs/security/THREAT_MODEL.md`; reporting policy is `SECURITY.md`.

Every row names an executable proof. The matrix was produced by reading the
actual handlers in `cmd/miragemesh` and `scripts/serve-web.mjs`, every CLI
mode, and the browser rendering code, then running the listed anchors. Test
names below are exact: Go anchors are required by
`scripts/verify-engine-tests.mjs`; browser and Node titles are the executed
`test(...)` titles.

## Findings

Audit result: **no critical or high severity findings** remain in the audited
local profile. The previously reported C01-C21 high findings (unrelated
container removal, impossible projection, identity collisions) are recorded as
remediated in `docs/evidence/C01-C21-review.json`.

Low observations retained deliberately:

- `style-src 'unsafe-inline'` is required by the existing inline accent style.
  It cannot execute script and no user-controlled style is rendered.
- The loopback APIs are reachable by any process of the local user. That is the
  documented single-user local model, not a multi-tenant authorization
  boundary; ADR-0003 explicitly excludes public multi-tenant admission.
- Read APIs carry no per-request authentication beyond the loopback Host/Origin
  checks. They expose no secret material and are `no-store`.
- No `Cross-Origin-Opener-Policy`/`Cross-Origin-Resource-Policy` headers are
  set. Cross-origin reads are already blocked by the absence of CORS and
  `frame-ancestors 'none'`; this is hardening, not a demonstrated defect.

## Explicit limits

Local Linux source and process proofs only. No penetration-test certification,
no physical access or OS compromise resistance, no public ingress, no hosted
multi-tenant authorization, no C30 clean-host workflow and no C40 release claim.
The evidence for this matrix is `docs/evidence/C27.json`.
