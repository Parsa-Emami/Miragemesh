artifact:

- `react-dom-MIT.txt` — React DOM 19.3.1, MIT
- `scheduler-MIT.txt` — scheduler 0.28.0, MIT

The project source is Apache-2.0; see `LICENSE` and `NOTICE`. Node.js, npm,
Podman and the pinned Alpine decoy image are host prerequisites pulled or
installed by the operator and are not redistributed in this artifact. Their
exact versions, digests, source routes and license links are recorded in
`docs/engineering/toolchain-lock.json` and `sbom.cdx.json`.
